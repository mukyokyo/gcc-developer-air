# GCC Developer Air (GDA) - Beta Release

拡張性と実用性を重視した、Python/PySide6ベースの軽量な統合開発環境（IDE）のベースシステムです。ローカルとリモートの境界をなくすファイルシステムと、各種ターミナル、LSP（Language Server Protocol）を統合した「開発のための道具箱」として機能します。

## 📦 本ベータ版（IDE本体のみ）の位置づけ
今回のリリースは、開発環境のコアとなる**IDE本体の先行公開**です。

*   **組み込み向けツールは未同梱:** コンパイラや書き込みツールなどのツールチェーンは含んでおらず、組み込み用途としては「空っぽ（スッカラカン）」のベースシステムです。
*   **内包されるもの:** エディタ本体、Python実行環境、LSP（clangd / pylsp）、ターミナル群、仮想ファイルシステム（VFS）、AIチャット。
*   **Python環境の同梱:** IDE自身を動かすためのPython本体と、単体で多少のスクリプト実行やテストが行える程度の基礎的なライブラリを内包しています。

## 🧰 独自ビルド・同梱されている主要コンポーネント
GDAは「インストールしてすぐ動く」ことを最優先し、ホスト環境のPythonやC++ビルドツールチェーンを一切汚染しないよう、通常は手動での環境構築やコンパイルが必要なコアコンポーネント群を**全て独自にビルド・パッケージ化**して内包しています。

*   **LSPサーバー群 (完全スタンドアロン化)**
    *   **`pylsp.exe`**: ホストのPython環境への依存を断ち切るため、PyInstallerを用いてソースから単一の実行ファイル（exe）として独自ビルドして同梱。
    *   **`clangd.exe`**: MSYS2 (UCRT64) 環境の強力なC/C++用Language Serverを、システムから抽出して単体同梱。
*   **MSYS2 (GDA最小サブセット)**
    *   `make` や `bash` をはじめとする、ビルドや統合ターミナルの動作に最低限必要な `msys64/usr` 内のツール群をポータブル化して同梱。ユーザーのPCにMSYS2をインストールする必要はありません。
*   **PySide6-QtAds (フルエクスポート・カスタムビルド版)**
    *   ドッキングUIの要となるAdvanced Docking SystemのPythonバインディングを同梱。
    *   通常版ではアクセスできない内部クラス（`CDockOverlayCross` 等）をPythonから直接制御できるよう、**C++ヘッダやCMakeフラグに独自パッチを当てて全シンボルをエクスポートした魔改造ビルド版**です。システムの純正ライブラリとの衝突を避けるための隠蔽ロード処理も適用済みです。
*   **通信・フォーマットユーティリティ**
    *   **`muxserial`**: 独自の透過型シリアルポートマルチプレクサ。
    *   **`yapf_third_party`**: Pythonフォーマッタ。本家 `yapf` のメンテナンス状況を考慮し、代替フォーク版として組み込み。
*   **専用開発フォント**
    *   **`PlemolJPConsoleNF`**: エディタおよび各種ターミナルでの文字化け（Nerd Fonts等のアイコン含む）を防止し、厳密な等幅表示を強制して視認性を担保するために標準組み込み。

## 🛠 主な機能とキーワード

検索や課題解決のフックとなる、GDAが備える実用的な機能群です。

**テキストエディタ ＆ LSP (Language Server Protocol)**
*   **マルチテキストエディタ:** ドッキングUIによる複数ファイルの分割配置・同時参照編集。
*   **C/C++ & Python 対応:** `clangd` と `pylsp` を統合。入力補完、定義・参照ジャンプ（タグジャンプ）、静的コード解析（エラーハイライト）。
*   **オムニボックス:** インクリメンタル検索、一括置換、エディタコマンド、Pythonスクリプト即時実行、AIアシストを単一の入力窓に統合。

**仮想ファイルシステム (VFS) ＆ ファイラー**
*   **透過的なファイル操作:** ローカルPC、SFTP（SSH）、MicroPythonのファイルシステムを同一のツリーUIでマウント・操作可能。
*   **自動同期:** ローカル環境のファイル変更自動検知、およびリモート環境の差分同期機能。
*   **ドラッグ＆ドロップ:** 異なるプロトコル間（例: ローカルからSFTPなど）でのシームレスなファイル転送。

**統合ターミナル ＆ リモート接続**
*   **各種専用ターミナル:** Bash、SSH、Serial（シリアルモニタ）、Python / MicroPython REPL の各ターミナルをタブで管理。
*   **ANSIエスケープコード対応:** 簡易的なエスケープシーケンスに対応したターミナル描画。
*   **マルチプロトコル:** SSH、Telnet、SFTP、シリアル接続など、開発に必要な通信規格をIDE内に一元管理。

**AI アシスト ＆ 自動化**
*   **AIチャット統合:** 主要なLLMバックエンドに対応した対話型アシスタントをドッキングUI内に配置。
*   **外部ツール連携の基盤:** Makefile自動生成のベース機能、DAP（Debug Adapter Protocol）インスペクタ機能など、将来的な組み込みツールチェーン連携に向けたフレームワークを内蔵。
